# 录放台 · 浏览器操作录制与自动化回放

在程序打开的受控浏览器里操作一次网页，录放台把操作整理成**可审阅、可编辑的工作流**；
之后点一下就按同样的步骤自动重放。单进程、单窗口、无系统标题栏，数据全部留在本机。

## 启动

- **封装版**：双击项目根目录的 `录放台.exe`（就在 `recorded-automation\` 这一层）。
  同级 `ms-playwright\` 是自带浏览器引擎（约 420MB），整个文件夹可以整体拷到别的电脑；
  若该目录被删，程序自动改用本机已装的 Microsoft Edge；两者都不可用时，界面会给出修复指令。
- **源码版**：`python -m ra.main`（依赖 `playwright`、`jsonschema` 与可用的浏览器引擎）。

窗口没有系统标题栏：顶部标题条由程序自己画（应用标记 + 名称 + 当前界面 + 运行状态计时 +
最小化/最大化/关闭）。拖动标题条移动窗口，双击铺满工作区；系统边框在窗口出现前就被去掉，
所以不会看到两层标题栏。首次启动是空的：这里不放示例数据，工作流和运行记录都来自你自己的操作。

## 使用流程

1. **工作台**（`Alt+1`）：顶部四张统计卡显示工作流数、最近运行成功率、待填秘密引用、当前浏览器引擎。
   填入页面地址 → `Enter` 或点「开始录制」。
2. **录制中**：左侧是受控页面的实时画面，右侧是正在生成的候选步骤；连续输入自动合并成一次 `fill`，
   其他来源的事件被丢弃并列出原因；密码类输入只记录"这是敏感字段"，不记录内容。
3. **停止并审阅**：逐条检查步骤。每条列出候选定位器（`role → label → test_id → text → css`）和它们在
   当前页面的匹配数量；多匹配或找不到的会被标出来，可以改定位值、换候选、调顺序、删步骤、补完成条件。
   「重新校验唯一性」按当前打开的页面重新数一遍匹配数。多匹配的步骤摊开候选列表供点选，
   找不到目标的步骤直接写出三步修复出路（换定位值 → 重新校验 → 或改完成条件/删掉这一步）。
   审阅页的「试运行草稿」按当前草稿立即跑一次，不用先保存。
4. **校验并保存**（`Ctrl+S`）：先过 JSON Schema（`ra/workflow.schema.json`），再过执行语义
   （步骤 ID 唯一、`start_url` 与 `origin` 同源、`role` 定位器带可访问名称、`start_url` 不含令牌参数）。
   有阻塞项时保存按钮不可用。保存时若秘密库还缺引用值，会直接跳到秘密库那一屏并列出缺的引用名。
5. **运行**：受控浏览器打开 `start_url`，按步骤执行；运行页显示步骤时间线、阶段日志与结果分类。
   停在「失败」或「已取消」时（这两步的动作都没发出去过）会出现**从失败步重试**：只跑剩下的步骤，
   已执行过的步骤绝不重跑，界面会写明本次跳过了几步；「未确认」不给这个按钮，只给人工检查清单。
6. **运行历史**（`Alt+2`）：每次运行的事实日志，点一行回到那次的结果页；工作流被删过会标出来。
7. **秘密库**（`Alt+3`）：工作流里只存引用名。填真实值后按当前 Windows 账户加密保存在本机，
   每行显示该引用被哪些工作流使用；缺值时运行会被直接拦下并指出引用名。
8. **设置**（`Alt+4`）：默认超时、无界面运行、代理、清空浏览器登录态、打开数据目录、运行端到端自检。

## 结果怎么读

| 结果 | 含义 | 程序会不会重试 |
| --- | --- | --- |
| 完成 | 所有步骤执行完，且设了完成条件的都被验证过 | — |
| 完成 · 未验证 | 步骤执行完了，但有动作没设完成条件，程序没有证据 | 不重试 |
| 未确认 | 动作已发出且**只发出一次**，之后超时/异常/取消，无法判断页面是否生效 | 不重试，停在当前步骤，给出人工检查清单 |
| 失败 | 在动作发生**之前**就停了（目标缺失、匹配多个元素、来源变化、缺秘密值） | 没有点击任何元素 |
| 已取消 | 你点了停止 | 停在当前步骤 |

程序重启后不会根据日志自动续跑；日志只记录事实，不反写工作流。「从失败步重试」是你手动点的那一下，
不是自动重试：它从停在的那一步开始跑剩下的步骤。从运行历史打开一个已经结束的运行，结果按日志里最后那条
终态事件读；日志里读不到终态就如实写「无记录」，不会替你判成成功。

## Agent API / MCP

程序之外还有一层本机工具接口，让任意 Agent（Tcode、Claude Code、Codex、任何 MCP 客户端）
不必读源码就能把工作流库当带 schema 的工具调用。契约见
`personal-agent-hub/docs/AGENT_API_STANDARD.md`，实现与逐项说明在 `agent/README.md`。

```bash
python agent/server.py            # 只监听 127.0.0.1:8795；端口被占自动 +1 并写 agent/.endpoint
node agent/mcp-server.mjs         # MCP stdio 桥；服务没起来会按 agent/launch.json 自己拉起
```

| 工具 | 风险 | 作用 |
| --- | --- | --- |
| `ra.status` | read | 版本、数据目录、工作流与运行计数、秘密引用名、设置、浏览器缓存解析 |
| `ra.list_workflows` | read | 已保存工作流的摘要（步数、动作、未验证步数、用到的秘密引用名与缺失项） |
| `ra.get_workflow` | read | 一份完整 Workflow v1 + Schema/执行语义双层校验结果 |
| `ra.validate_workflow` | read | 对一份定义跑保存前的双层校验，不写盘 |
| `ra.save_workflow` | write | 写入或覆盖工作流文件，**必须 `confirm:true`**；有阻塞项被拒 |
| `ra.run_workflow` | exec | 真实回放，返回步骤时间线与结果分类，**必须 `confirm:true`**；`from_step` 是人工指定的从失败步续跑 |
| `ra.run_history` | read | 最近运行摘要，或某次运行的完整时间线与阶段事件 |
| `ra.list_secret_refs` | read | 秘密引用名、长度、被哪些工作流用、缺哪些；**永不返回秘密值** |

工具全部复用 `ra/api.py` 的界面门面与 `ra/store.py`、`ra/secrets.py`、`ra/engine.py`、`ra/core.py` 的真实能力，
没有假数据。删除类动作（删工作流、删秘密引用、清空浏览器登录态）不暴露给 Agent；秘密值只能在界面里填写，
缺值时运行会在打开浏览器之前就被拦下并列出全部引用名。

## 首版边界（界面里也写明了）

- 单个标签页、单个来源（origin）；跨站登录、验证码、文件上传、拖拽、浏览器工具栏操作不在范围内。
- 动作类型：`click`、`fill`（含下拉选择）、`hotkey`、`wait_for`。
- 不退化成屏幕坐标定位；多匹配必须人工选定并重新校验后才允许保存。
- 录制时不保存原始按键流；候选事件来自页面脚本，因此必须经人工审阅才写入工作流。

## 自检与验证

| 目的 | 命令 / 入口 |
| --- | --- |
| 界面与桥接（真实窗口） | `录放台.exe --verify` 或 `python -m ra.main --verify [地址]` |
| 后端链路（真实浏览器 + 本地站点） | `录放台.exe --selfcheck`、`python -m ra.main --selfcheck`，或设置页按钮 |
| 单元与契约测试 | `python -m unittest discover -s tests -t .` |

界面自检会在真实窗口里检查标题条、七个界面、确认框、录制开始/停止、保存、运行、时间线、日志、
删除与快捷键，并把截图写到 `%LOCALAPPDATA%\RecordedAutomation\ui-shots\`。
启动失败时看 `%LOCALAPPDATA%\RecordedAutomation\startup-error.txt`。

## 数据位置

`%LOCALAPPDATA%\RecordedAutomation\`：`workflows/`、`journal.jsonl`、`secrets.json`、`profile/`（受控浏览器）、
`shell-profile/`（界面窗口）、`exports/`、`settings.json`、`ui-shots/`。设置页可一键打开该目录。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `ra/core.py` | 平台中立契约与回放策略（Runner 只看协议，不导入浏览器库） |
| `ra/recorder.py` + `ra/ui/record_script.js` | 页面事件桥接、来源复核、候选定位器计数 |
| `ra/normalizer.py` | 候选事件归并成草稿，草稿落为 Workflow v1 |
| `ra/driver.py` | Playwright 适配器：定位、执行、执行前复核来源与唯一性 |
| `ra/session.py` | 会话协调器：受控浏览器、录制/回放互斥、取消、状态机 |
| `ra/store.py` `ra/journal.py` `ra/secrets.py` | 工作流存储与校验、落盘日志、DPAPI 秘密库 |
| `ra/shell.py` `ra/winframe.py` `ra/engine.py` | 无边框应用窗口、JS↔Python 桥、浏览器引擎选择与回退 |
| `ra/api.py` `ra/ui/` | 界面门面与前端（工作台/录制/审阅/运行/历史/秘密库/设置） |
| `ra/selfcheck.py` `ra/uiverify.py` `ra/fixture.py` | 端到端自检、窗口内自检、本地测试站点 |
| `agent/` | Agent API 服务、工具层与 MCP 桥（见下一节） |
| `build/` | 图标与 PyInstaller 配置 |
